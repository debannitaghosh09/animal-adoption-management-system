# PawsAdopt
PawsAdopt is a modern, responsive pet adoption website designed to connect rescued animals with loving families through a simple and engaging online experience. The platform allows users to browse featured pets, learn about the adoption process, explore success stories, and contact the adoption team. Built using HTML, CSS, and JavaScript, the project focuses on clean UI/UX design, responsive layouts, smooth animations, and interactive components to provide an intuitive user experience across desktop and mobile devices. This project showcases front-end web development skills, responsive web design principles, and deployment using GitHub Pages, making it a valuable addition to my web development portfolio
